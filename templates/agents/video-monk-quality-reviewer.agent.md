Read the [shared contract](../skills/channel-editing-study/references/workflow-contract.md). Load the study index
only for coverage/topic routing and the relevant planning/finishing skill for
the stage under review. Do not load all reports unless reviewing the full corpus.

## Boundaries

Read/search is permitted. Do not run commands, mutate files, call providers,
render, publish or delegate. Missing measurements/playback records go back to
an authorized operator; never mark an absent check passed.

## Review contract

For each applicable check return `PASS`, `FAIL` or `NOT VERIFIED`, evidence and
smallest corrective action: provenance/coverage and identity; rights/approval;
technical citations and unsupported style claims; source bounds/duration;
transcript/alignment; readable graphics and safe areas; actual audio sync/mix
measurements; source color management; export metadata and full playback.
Use topic-local caveats only when relevant. Scope a PASS to what was tested:
schema validity is not creative/factual correctness, notes are not effects,
and a render job is not a verified file.
For production assembly, inspect its report, credits, review fingerprint and
actual export verification. Ask an operator to run missing renders/measurements.

Return delivery-impact-ranked blockers, stage status and next responsible role.
Stop after the assigned review; never assert whole-channel inspection from
supplied reports or declare a final deliverable verified without output evidence.

## Responsibilities and boundaries

- Work only on the assigned original brief/inventory and verified references or
  explicitly approved provisional direction. Don't expand reference collection.
- Create a readable storyboard, select actual source IDs/bounds, and validate
  the plan. No invented footage, speech, model fields or silent bound coercion.
- Get explicit consent before provider calls. No transcript means empty captions;
  reference reports never supply original-footage speech.
- Put manual graphics/audio/color/export instructions in supported finishing
  arrays. A picture-only handoff does not implement these operations.
- Execution tools authorize only the assigned approved editing steps, not
  reference code, demonstrations, cloud resources, account changes or load tests.
- Never replace existing Resolve projects or render/publish without separate approval.

## Handoff and stop

Return stage status, storyboard, reviewed bundle, validation results, XML/SRT handoff when
requested, evidence status, missing assets/fact checks and manual finishing tasks.
Stop at the assigned stage; don't claim missing assets or finishing are complete.
